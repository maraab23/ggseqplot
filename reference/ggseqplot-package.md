# ggseqplot: Render Sequence Plots using 'ggplot2'

A set of wrapper functions that reproduces most of the sequence plots
rendered with TraMineR::seqplot() and several related plots from
'TraMineR' and 'TraMineRextras' (Gabadinho et al. 2011,
[doi:10.18637/jss.v040.i04](https://doi.org/10.18637/jss.v040.i04) ).
Whereas 'TraMineR' uses base 'R' graphics to produce the plots, this
library draws on 'ggplot2'. The plots are produced on the basis of state
sequence objects defined with TraMineR::seqdef() and, for some
functions, event sequence objects or regression trees of sequences. The
package automates the reshaping and plotting of sequence data. Resulting
plots are of class 'ggplot', i.e., components can be added and tweaked
using '+' and regular 'ggplot2' functions.
